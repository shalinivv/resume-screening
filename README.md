# 📄 Resume Screening using NLP

An intelligent NLP-powered tool that screens resumes and identifies the most relevant candidates based on job descriptions. Built with Streamlit for an interactive web-based interface.

![Logo](main_web_app/Images/logo.png)

---

## 🚀 Features

- Automated resume screening using Natural Language Processing (NLP)
- Matches resume content with job requirements
- User-friendly Streamlit web interface
- Generates detailed reports for analysis

---

## ⚙️ Setup Instructions

To get started with the project, follow these steps:

```bash
# Navigate to your project directory
cd /path/to/folder

# Install the required Python dependencies
pip install -r requirements.txt
```

---

## ▶️ Running the Application

Once the dependencies are installed, launch the Streamlit app with the following commands:

```bash
# Navigate to the main web application directory
cd main_web_app

# Run the Streamlit app
python -m streamlit run app.py
```

The web application will open in your default browser, displaying the resume screening dashboard.

---

## 📊 Output

The application displays candidate matching results and analytics in a clean, interactive Streamlit interface.
